# Daegon Music

Daegon Music is a weekly streaming-chart experience inspired by the information architecture of Spotify Charts, using original Daegon Charts data and branding.

## Current scope

- Weekly only
- Global market
- Top 50 Streaming Songs
- Real weekly streaming data sourced from the Daegon Charts spreadsheet
- Position movement
- Weekly streams
- Peak
- Weeks on chart
- Total streams
- CSV export
- Responsive layout

The project is not affiliated with Spotify. Spotify Charts is used only as a product/interface reference.

## Data source

Daegon Charts → `Streaming Songs`

Latest week included in this initial version: **03/10/2026**.

## Stack

HTML, CSS, JavaScript.
